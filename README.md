# Biopython

A simple web-based DNA sequence analysis app built with HTML, CSS, and JavaScript.

## Overview
This project helps analyze DNA sequences by computing common biological metrics such as:
- sequence length
- base counts (A, C, G, T)
- GC and AT percentages
- reverse complement
- mRNA transcription
- protein translation
- open reading frames (ORFs)
- restriction enzyme site detection

## Features
- Paste a DNA sequence or FASTA text
- Upload a sequence file from the computer
- View base composition visually
- Export the analysis as a text report
- Use a modern browser interface

## How to use
1. Open `index.html` in a browser.
2. Paste a DNA sequence or upload a file.
3. Click `Analyze sequence`.
4. Review the results and export the report if needed.
